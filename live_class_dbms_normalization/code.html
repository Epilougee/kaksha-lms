Boyce-Codd Normal Form (BCNF) Rule Criteria

A relation R is in BCNF if and only if for every non-trivial functional dependency X → Y, X is a superkey of R. Violation triggers lossless decomposition.

Base Relation Violation: R(A, B, C)
Candidate Keys: {A, B} Violation: C → B (C not superkey)
Normalized Decomposition: R1 & R2
R1 (C, B) C determines B
C is Primary Key
R2 (A, C) A, C pair
{A, C} Superkey
